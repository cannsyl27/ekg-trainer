# Telemetry Master EKG Quiz

An interactive web-based EKG learning application designed to help nurses read strips, spot diagnostic indicators, and track heart rhythms.

## 🚀 Deployment Instructions for GitHub Pages
1. Create a public repository named `ekg-trainer` (or anything you prefer).
2. Upload this `index.html` file into that repository.
3. Go to **Settings** > **Pages** on your repository.
4. Set the Source dropdown to **Deploy from a branch**.
5. Select **main** (or your active branch) and click **Save**.
6. Your application will be live at: `https://<your-username>.github.io/<repository-name>/`
